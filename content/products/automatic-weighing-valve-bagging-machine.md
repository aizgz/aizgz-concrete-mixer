## Product description

The source describes two valve-bag packing options: an impeller / rotor-type valve bag packer and a screw-type valve bag packer. The equipment is used for automatic quantitative packing of fine powder materials, including dry-mix mortar, putty powder and thermal-insulation mortar, as well as other materials with similar properties.

The automatic weighing and quantitative valve-bag packing machine is described as comprising an automatic feeding system, weighing unit, bag-clamping unit, exhaust / return-air system and electrical control unit. The source states that the operator inserts the bag and the machine automatically completes the subsequent packing process, reducing manual gate operation and bag handling.

## Features and advantages listed in the source

1. High automation: an induction switch is used; opening, filling, weighing and bag release are described as automatic operations.
2. Weighing control: the computer uses fast and slow feeding flow control.
3. Bag-air handling: a two-layer return-air discharge spout is described as exhausting air from the bag while reducing dust.
4. Integrated electromechanical control: human-machine control supports parameter adjustment, data recording and storage.
5. Multi-stage feeding: large, medium and small feeding rates are used to improve working speed.
6. Enclosed dust-control construction: the source describes an overall enclosed, dust-resistant structure.
7. Labour and working conditions: the source claims that automatic operation can save 3–4 workers and reduce manual workload. This is a source claim, not a guaranteed labour saving for every installation.
